# دليل استخدام Omni-Agent Command Center

## التشغيل

شغّل الخادم ثم افتح المسار الجذري في المتصفح:

```bash
uvicorn backend.main:app --reload --port 8000
```

ثم افتح `http://127.0.0.1:8000`.

## اختيار نمط المهمة

| النمط | متى يستخدم | سلوك النظام |
| --- | --- | --- |
| **Auto** | الخيار الافتراضي لمعظم المستخدمين | يختار الخادم المسار الفردي أو متعدد الوكلاء وفق طول المهمة وإشارات التعقيد |
| **Single Agent** | سؤال أو مهمة مركزة وسريعة | ينفّذ دورة التخطيط، التنفيذ، والمراجعة داخل محرك واحد |
| **Multi-Agent** | تحليل، مقارنة بدائل، بحث، أو مخاطر | يوزع المنسق المهمة على البحث والتحليل والمخاطر ثم يدمج النتائج بعد المراجعة |

## أمثلة مفيدة

### قرار سوق جديد

اكتب: `حلل فرصة سوق جديدة، قارن المنافسين، حدد مؤشرات النجاح، وافحص مخاطر التنفيذ.`

ستشاهد مساهمات وكلاء البحث والتحليل والمخاطر، ثم قراراً موحداً قابلًا للمراجعة.

### تنظيم استجابة حادث تقني

اكتب: `ضع خطة استجابة لحادث تقني: حدد الأسباب المحتملة، خطوات العزل، نقاط التحقق، ومخاطر أي إجراء.`

استخدم المخرج بوصفه مسودة تشغيل ومراجعة؛ لا يغير النظام خوادم أو خدمات خارجية من تلقاء نفسه.

### حفظ تفضيل مستمر

اكتب: `تذكر أنني أفضل تقارير مختصرة جداً باللغة العربية.`

يحفظ النظام العبارة الصريحة كتفضيل دلالي، ويعيدها في السياق عند المهام اللاحقة ذات الصلة.

## قراءة الواجهة

توضح بطاقات الحالة ما إذا كان الخادم متصلاً، وعدد سجلات الذاكرة، ونوع مخزن المتجهات، وعدد الأدوات المسموح بها. تظهر بطاقة "تنسيق الوكلاء" الوكلاء المشاركين في المهمة ووضع المراجعة. تعرض لوحة الذاكرة أحداث الجلسة الأخيرة للمستخدم المحدد.

> لوحة Command Center تجعل تشغيل النظام قابلاً للرؤية، لكنها لا تمنح أي صلاحيات خارجية جديدة. تظل الأفعال مثل إرسال رسالة أو تعديل بنية تحتية مقيدة بأداة مخصصة وتأكيد بشري.
