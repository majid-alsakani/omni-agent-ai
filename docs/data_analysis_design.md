# تصميم ميزة Data Analysis Lab

## الهدف

إضافة مسار تحليل CSV عملي داخل Omni-Agent Command Center. يرفع المستخدم ملفاً صغيراً، ويُحلله ثلاثة وكلاء متخصصون، ثم تظهر نتيجة تنفيذية قابلة للفهم دون الحاجة لكتابة كود أو SQL.

## خط معالجة البيانات

| الوكيل | مسؤولية التنفيذ | مخرجاته |
| --- | --- | --- |
| **Data Profiling Agent** | فحص البنية والأنواع والقيم الناقصة والوصف الإحصائي | عدد الصفوف والأعمدة، الأنواع، الأعمدة الرقمية والفئوية |
| **Insight Agent** | البحث عن التباين والارتباطات والتوزيعات الملفتة | أقوى علاقات رقمية، أعلى تباين، تركيز الفئات |
| **Data Quality Agent** | قياس جودة الملف من التكرار والقيم الناقصة والثوابت والقيم الشاذة | درجة جودة، تحذيرات، وإجراءات مقترحة |
| **Synthesis Agent** | جمع المخرجات في ملخص تنفيذي عربي | ملخص، فرص، ومخاطر قبل اتخاذ القرار |

## حدود الأمان والخصوصية

يقبل المسار CSV فقط، ويضع حداً لحجم الملف. لا يحتفظ المحرك بالملف المرفوع؛ يحتفظ فقط بملخص حدث تحليلي قصير ضمن الذاكرة العرضية، مع اسم المصدر وإحصاءات مجمعة. لا يرسل البيانات إلى مزود خارجي في النسخة الحالية.

## واجهة API

`POST /analyze-data` يستقبل ملف CSV و`user_id` و`session_id` عبر multipart، ويرجع هيكلاً منظماً يتضمن المخرجات لكل وكيل، مؤشر الجودة، والملخص التنفيذي.

## تفاعل الواجهة

تُضاف منطقة **Data Analysis Lab** إلى Command Center. يختار المستخدم ملف CSV ثم يضغط «حلل البيانات». تُعرض بطاقات للصفوف والأعمدة ودرجة الجودة، ثم ملاحظات الوكلاء وملخص تنفيذي في منطقة النتائج الحالية.
